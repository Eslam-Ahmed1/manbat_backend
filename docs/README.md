# Manbut Backend

Manbut is a comprehensive backend service built on Node.js and Express to manage plants, diagnostic scans, general articles, and a fully featured e-commerce store with catalog navigation, shopping cart capabilities, and order placement.

## 📖 API Documentation

Complete documentation for all endpoints is available here:
* [API Documentation](docs/api_documentation.md)

This includes:
* **🍃 Articles & Plants:** Endpoints for general articles, direct plant articles (including aliases and typo-tolerant routing), and individual plant catalogs.
* **🛍️ Store / Shop:** Details on products, catalogs, user shopping carts, and order checkout pipelines.
